# Portfólio do Pedro

Este é o meu portfólio pessoal, desenvolvido para apresentar minhas habilidades, projetos e formas de contato.

## Sobre o projeto

O site contém:

- Uma apresentação pessoal
- Uma seção sobre mim
- Minhas principais habilidades
- Uma seção para meus projetos
- Um formulário que abre uma mensagem no Gmail
- Um botão para copiar meu endereço de e-mail
- Um design responsivo para computador e celular

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.
4. Como alternativa, use a extensão Live Server no VS Code.
